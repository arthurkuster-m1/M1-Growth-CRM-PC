# Texto estruturado das páginas de Estratégia

Escreva (ou cole) a página inteira de uma vez: Estratégia › qualquer página › **Importar de texto**.
Para editar fora do app: **Copiar a página como texto**, ajuste, e importe de novo.

```
# Título grande      ## Título médio      ### Título pequeno
Um parágrafo. Linhas seguidas formam um parágrafo; linha em branco separa.
- marcador      1. numerado      [ ] checklist
> atencao: destaque (tons: info, sucesso, atencao)
---   (linha divisória)

::: metricas      rótulo | valor | detalhe (opcional)
::: fluxo         título | texto
::: cards         título | texto
::: matriz swot   4 linhas: título | texto   (::: matriz = neutra)
::: piramide      título | texto, do topo para a base   (::: funil = funil)
::: tabela        1ª linha = colunas; demais = linhas
::: citacao       texto | autor
::: toggle        título | texto
::: links         rótulo | https://...
::: imagem        legenda (o arquivo se envia depois)
:::               fecha o bloco
```

- `|` separa colunas; para um `|` no texto, escreva `\|`.
- Linha que deve começar com `#`, `-`, `>` ou `:::` mas ser texto: ponha `\` na frente.
- Tudo ou nada: com qualquer erro nada é importado, e cada erro mostra a linha.
- Não têm forma em texto (ficam de fora da cópia): oferta, ficha, calculadora, paleta, antes/depois, imagem-texto e imagens já enviadas.
