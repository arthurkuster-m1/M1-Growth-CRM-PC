titulo: Criar tarefas a partir de um plano, para um cliente, pelo menu da página Tarefas
---

No botão "Nova tarefa" (seta), além de "Criar a partir de um modelo" agora há "Criar a partir
de um plano", com todos os planos já cadastrados e um ícone próprio. Ao escolher um plano
abre um popup para escolher o cliente e acertar as datas: o início do plano e, se quiser, o
prazo de cada tarefa. "Criar" grava todas as tarefas do plano, na ordem, ligadas ao cliente.

O item que abria os planos passou a se chamar "Gerenciar planos de tarefa", e os planos
novos aparecem no menu assim que você fecha a gestão.
