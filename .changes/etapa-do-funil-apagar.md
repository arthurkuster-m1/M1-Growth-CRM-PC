titulo: Em cada etapa do funil, o botão agora se chama "Apagar"
---

Na edição das etapas do funil (inclusive na aba de Campanhas), o botão que tirava uma etapa do
quadro passou de "Arquivar" para "Apagar", com ícone de lixeira, para ficar claro que serve para
remover uma etapa criada sem querer. Continua guardando o histórico; se houver negócios na etapa,
pergunta para onde eles vão.
