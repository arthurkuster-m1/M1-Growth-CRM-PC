titulo: Agenda no celular: arraste para o lado para trocar o período
---

No celular, arrastar o dedo para o lado na Agenda troca o período: da direita para a esquerda vai
para o próximo, da esquerda para a direita volta ao anterior. Vale para Dia, 3 dias, Semana e Mês,
com o mesmo passo das setas.
