titulo: Menu lateral do celular mais compacto, para caber inteiro numa tela
---

No celular, o espaçamento entre os itens do menu lateral ficou menor, de modo que todas as opções
(do Início ao Financeiro, mais Configurações) aparecem de uma vez, sem precisar rolar para cima e
para baixo. No computador o menu continua como estava.
